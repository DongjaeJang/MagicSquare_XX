## 전제

STEP 1 Mom Test 인터뷰가 완료되어 **진짜 문제**와 **증거 3줄**이 확보된 상태에서 실행한다.

### Mom Test 결과 (입력)

- **페르소나:** 4×4 **부분** 마방진 학습자. 빈칸 2개(`?` 또는 0), 1~16, **10선** 각 합 **34**
- **진짜 문제 (한 문장):** 4×4 부분 마방진(`?` 2칸)을 **손으로** 채운 뒤 **10선 합 34** 확인 시 **대각선을 까먹어** **20분**을 쓰고, **다 채운 뒤** 틀림을 알며 **`?` 두 칸만 고친 뒤 10선 전부 재검증**한다
- **Mom Test 증거 3줄:**
  1. “**오늘** … **20분** 걸렸는데 못 풀었어. **대각선 하나를 빼먹었**거든” ✅
  2. “**다 채우고 나서**” (틀렸다는 걸 알았다) ✅
  3. “**두 칸만 고쳤어**” → “**다시 더해서 맞췄지**” / “**다 확인했다**” ✅

## 작성 규칙

- **솔루션 최소화:** Solver · GridUI · ECB 전체 앱 · PyQt · Cursor 등 **솔루션 이름**을 주제·진짜 문제에 넣지 않는다
- **Mom Test 연결:** 성공 기준 3개는 반드시 **증거 3줄**과 1:1로 연결한다
- **표면 문제 분리:** “~~프로그램 만든다” 류는 **하지 않을 것**에만 둔다
- **8계층 범위:** 이번 세션은 **Rule · Command · (Skill) · Test Loop** 만. Entity · Boundary · Solver는 **다음 세션**
- **도메인 고정:** 4×4, 빈칸 2개, 1~16, **10선**, 합 **34**
